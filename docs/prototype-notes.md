# Игра решений — LangGraph + OpenAI

Web prototype based on the supplied Russian game concept and two example stories.

## Run

```bash
cd /workspace/dima_project
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock.txt
.venv/bin/streamlit run app.py --server.address 0.0.0.0 --server.port 8501 --server.headless true
```

Open the Streamlit application in your deployment/browser. Enter an OpenAI API key in the password field, or supply `OPENAI_API_KEY` through your runtime's secure environment settings. Never commit a key. `OPENAI_MODEL` defaults to `gpt-4.1-mini`; choose a model available to your account. API usage incurs OpenAI charges. Team answers and story context are sent to OpenAI in API mode. Demo mode makes no model calls and does not assess answers.

## How it works

Select a team and story, read the unchanged author text, and submit a free-text decision. LangGraph runs structured assessment and routes to clarification or continuation. Feedback considers the actual answer, alternatives, risks and roles. Timing is recorded in seconds; it is not an enforced deadline or a psychological score. Teams can revise decisions before continuing. Download results as JSON.

This first version follows five authored checkpoints per story. It does not generate new story branches or select random complications: the author's listed complications are displayed as authored alternatives. Teams discuss which applies. All original paragraphs, including author notes and example endings, are available in the sidebar without edits. AI feedback is separate from author text. Final-stage cooperation is facilitated by a human sharing team results; automatic multiplayer synchronization and speech input are not implemented. Team state lasts only within the current Streamlit browser session.

The original evaluative claims in the examples are game material, not medical or psychological guidance. The agent accepts reasonable alternative solutions and does not treat rest or refusing a purchase as inherently wrong.

## Data

- `data/author_text.json`: all 98 nonempty DOCX paragraphs and 29 XLSX diagram labels, preserving their text.
- `data/scenarios.json`: playable prompts extracted verbatim from those paragraphs. Alternative example outcomes remain in the full source view rather than being presented as events that actually occurred.
- `data/example_answers.csv`: 10 UTF-8 BOM sample rows, with author text followed by example team answers and feedback. Examples were written for illustration, not generated by a live API request.

## Validation

```bash
.venv/bin/python -m pytest -q
```

Tests exercise the real LangGraph with a fake structured model, verbatim source preservation and a Streamlit demo interaction. Live API output requires a valid key and is not covered by offline tests.
