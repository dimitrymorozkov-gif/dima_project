## Ветка DeepSeek API — 20 октября 2026 года

Полная локальная сборка: **143 теста прошли**. Публичная сборка: **142 теста прошли, 1 проверка полного исходного текста пропущена**. `pip check` не обнаружил конфликтов зависимостей; новые пакеты не потребовались.

DeepSeek проверен без внешних запросов: настоящий ChatOpenAI, LangChain LCEL, OpenAI SDK и Pydantic используют `httpx.MockTransport`. Проверены URL `/chat/completions` на `api.deepseek.com`, ключ DeepSeek в Authorization, JSON Output, лимит `max_tokens=4096`, отключенный thinking и отсутствие несовместимого `max_completion_tokens`. Ключи и модели OpenAI/DeepSeek изолированы.

Проверены неверный ключ (подставной HTTP 401), пустой и оборванный JSON, невалидная схема, уточнение, сохранение DeepSeek-игры, восстановление, запрет смены провайдера и экспорт происхождения оценки. Через Streamlit AppTest проверены выбор провайдера и отсутствие перехода в демо при недостающем ключе.

Живой API DeepSeek не вызывался: `DEEPSEEK_API_KEY` не настроен, а текущая управляемая среда не разрешает домен `api.deepseek.com`. Доступ к аккаунту, доступность выбранной модели и качество живой оценки остаются непроверенными.
